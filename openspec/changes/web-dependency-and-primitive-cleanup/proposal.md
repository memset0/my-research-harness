## Why

The Web app still declares dependencies nothing imports (the eight per-package
`@radix-ui/react-*` modules superseded by the `radix-ui` aggregate,
`@hugeicons/*`, `date-fns`, `date-fns-tz`, `cn`, `tailwindcss-animate`,
`@tanstack/react-table`), and four shadcn primitives under
`apps/web/components/ui/` (`context-menu`, `popover`, `table`, `hover-card`)
were hand-written or hand-extended instead of generated by the shadcn CLI,
which violates the repository rule against forking primitives and makes the
next `shadcn add --overwrite` silently drop local edits. Two owner actions
also still use the browser-native `window.confirm`, which bypasses the themed
dialog system.

## What Changes

- Remove the unused Web dependencies listed above from `apps/web/package.json`
  and refresh `pnpm-lock.yaml`. `js-yaml` and `yaml` both stay because each is
  imported by Web code (frontmatter parsing vs. comment-preserving YAML
  document edits). The stale `cn@^0.3.0` declaration is dropped as unused, but
  the regenerated primitives reintroduce `cn@^0.4.0`: the current shadcn
  registry for this style imports `cn` from that package and declares it as a
  component dependency, so it is a real runtime dependency again.
- Regenerate `components/ui/{context-menu,popover,table,hover-card}.tsx` with
  `shadcn add --overwrite --yes`. Any application-specific styling or export
  the upstream file does not provide moves into a wrapper component outside
  `components/ui/` instead of an edited primitive.
- Install the shadcn `AlertDialog` primitive through the CLI and replace the
  `window.confirm` prompts in the Git history dialog (discard unsaved commit
  note) and the wiki review panel (unverify a commit) with it.
- Update the `web-layout` requirement on shadcn primitives so it reflects the
  current CLI-generated, never-hand-edited contract and the confirmation
  dialog convention.

## Capabilities

### New Capabilities

(none)

### Modified Capabilities

- `web-layout`: the "shadcn primitives replace hand-rolled UI components"
  requirement now states that primitives are CLI-generated and never edited in
  place, and that confirmation prompts use the shadcn AlertDialog rather than
  browser-native dialogs.

## Impact

- `apps/web/package.json`, `pnpm-lock.yaml`.
- `apps/web/components/ui/{context-menu,popover,table,hover-card,alert-dialog}.tsx`
  and possibly wrapper components plus their importers
  (`experiment-results-table.tsx`, `github-permalink-preview.tsx`,
  `inbox-shell.tsx`, `report-pane.tsx`, `wiki-pane.tsx`, `wiki-shell.tsx`,
  `journal-view.tsx`, `file-access-settings-panel.tsx`,

- `apps/web/components/git-history-dialog.tsx`,
  `apps/web/components/wiki-review-panel.tsx` and their tests.
- Release surface: central (Web) only. No CLI, skills, or filesystem change.
