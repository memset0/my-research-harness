## Context

Four v1 components exist under `apps/web/lib/wiki-components/<name>@<N>/` with per-descriptor YAML parsing, info-string attributes, a `RENDERABLE` map plus switch, a hardcoded core name list, and a skill that sends agents to `memon wiki components show`. The owner wants one input model (one object per block, from the block or from a Python function), per-document result caching, explicit recompute from CLI and dashboard, generated docs, and a rename. See proposal.md.

## Goals / Non-Goals

- Goals: one payload model; one descriptor directory as the single source of truth with generated barrels/docs; typed descriptor→renderer link; generic "locate block by id → edit payload" helper; execution + cache + recompute with honest failure semantics; four components rebuilt on the new contract; skill generated by script.
- Non-Goals: compatibility with old block names; automatic migration; remote (non-local) execution; a general job queue; charts beyond line/bar; sandboxing Python beyond cwd/timeout/root containment (the project's own code already runs on this machine).

## Decisions

1. **Declaration parsing** (`apps/web/lib/components/declaration.ts`, pure, no fs): `parseComponentDeclaration(info)` → `{ lang, type, version|null, id|null } | null`; strict token grammar; extra tokens → null-with-reason so the registry can emit `WIKI_COMPONENT_INVALID`. `scanFencedBlocks` stays. The same parser is copied into `@memon/core` (`packages/core/src/wiki/components.ts`) for structural lint (`WIKI_COMPONENT_UNPINNED`, `COMPONENT_ID_DUPLICATE`) and for the CLI runner; the generated `component-names.generated.ts` gives core the known type list.
2. **Payload derivation** (`payload.ts`): `derivePayload({lang, body})` → `{ kind: 'static', value }` | `{ kind: 'executable', spec: {script|code, kwargs} }` | `{ kind: 'error', field, message }`. YAML via `yaml` `parseDocument` (core schema, `uniqueKeys`, alias rejection — the checklist parser generalised); JSON via `JSON.parse`; else `{ data }`. Reserved keys: `script`, `code`, `__*`.
3. **Descriptor contract** (`types.ts`): `defineComponent({ type, version, description, useWhen, schema, example, invalidExamples, fixtures })` returns a descriptor whose `Data = z.infer<schema>`; validation and zod-issue→diagnostic mapping happen once in `registry.ts` (`validatePayload`). Renderer file `render.tsx` exports `Render: ComponentRenderer<Data>` with props `{ data, block: { id, type, version, executable, document: { project, path } | null, resourceUrl(relative) } }`. Directory: `apps/web/lib/components/<type>/v<N>/{index.ts,render.tsx,index.test.ts}`; generated `apps/web/lib/components/registry.generated.ts` (descriptor imports) and `renderers.generated.tsx` (lazy-free static imports). `index.tsx` dispatches from the generated map; no hand list.
4. **Generator** `scripts/component-docs.mjs` (run through `pnpm --filter @memon/web exec tsx ../../scripts/component-docs.ts` wrapper so zod descriptors load): scans `apps/web/lib/components/*/v*/index.ts`, emits the two barrels, `packages/core/src/wiki/component-names.generated.ts`, and the marked section in `packages/skills/memon-components/SKILL.md` (table + per-type field list derived from zod: uses `schema.shape`, `.isOptional()`, `.description` for meaning). `--check` diffs. Wired into `packages/skills` `build`/`prepack` like `wiki-kinds.mjs`.
5. **Block context on every surface**: `markdown.tsx` gains an optional `document?: { project, path }` prop; wiki/experiment/run/report surfaces pass their document path. The renderer's `resourceUrl(rel)` builds `/api/doc-assets/<project>/<encoded document dir>/<rel>`; without `document` it returns null and renderers show their fallback.
6. **Document asset route** `apps/web/app/api/doc-assets/[project]/[...path]/route.ts`: `path` = project-relative file path; realpath + `assertWithinProjectRoots`; serves cache JSON (no-store) and images (extension allow-list, SVG CSP). Absolute figure paths are accepted by the renderer only when inside a project root (server decides; client just requests). Replaces the figure-specific `shared` branch of `wiki-assets`.
7. **Execution runtime** in `@memon/core` (`packages/core/src/components/{declaration.ts,payload.ts,execute.ts,cache.ts}`; the CLI depends on core, not backend, so the runtime lives there and backend/web/CLI all import it): given project root, document path, block `{id, type@N, spec}`: resolve script path (document-relative or absolute, must realpath inside root) or write `code` to a temp file; spawn `<python> - <bootstrap>` that imports the module/loads the function, calls it with kwargs + injected `__id/__md_file_path/__project_root/__assets_dir`, and prints `json.dumps(result)` between sentinel lines on stdout; enforce object return, timeout (default 120 s), cwd = root. Result → `writeCache()` compares canonical JSON of data (stable key order) with the existing file; writes `{...data, __md_file_path, __component_type, __component_id, __updated_at, __source_hash, __duration_ms}`; on failure rewrites only `__last_error` into the existing file (or creates a file with `__last_error` and no data when none existed). Python command from project config `execution.python` (default `python3`); timeout `execution.component_timeout_ms`.
9. **Write-back helper** `apps/web/lib/components/rewrite.ts`: `replaceBlockPayload(document, { id | index, expectedPayload, next })` preserving fence/indent/CRLF; `setChecklistStatus` becomes a thin caller. Executable checklists: controls disabled.
10. **datatable views** with recharts (`pnpm add recharts` in apps/web; shadcn `chart` primitive via `pnpm dlx shadcn@latest add chart --yes`). Tabs (shadcn Tabs) outer, Select inner; series → one `<Line>/<Bar>` per distinct value; first-appearance ordering; non-numeric `y` skipped with a count notice. Table view reuses the existing table rendering from `memon-data@1`.
11. **Removals**: `apps/web/lib/wiki-components/**`, `apps/web/components/wiki-components/**`, `/api/wiki/components/**`, CLI `wiki components` + `lint --central`, `listDataProvenance`/`migrateComponents`, `WIKI_DATA_*` diagnostic codes, `docs/wiki/assets` figure convention, `memon-author-components` (retired via `retired-skills.json` digest of its current tree). Mock fixtures (W0001/2/3/5/6/9/10) rewritten to the new syntax; `W0009` image moved to `W0009-figure-gallery__assets/`.
12. **Rename scope**: type names `datatable`, `figure`, `embed`, `checklist`, all `@1`. Old info strings render as ordinary code.

## Risks / Trade-offs

- Python execution from the dashboard runs arbitrary project code as the service user → owner-only, local-execution projects only, documented; same trust level as `bash <entry>` today.
- recharts adds a client dependency; kept behind the datatable renderer so other surfaces do not pay for it (dynamic import in `render.tsx`).
- Generated files are committed; drift caught by `--check` in the skills build and by a registry test.
- Per-block cache fetches add one request per executable block; acceptable (no-store, small JSON).
- Big cutover across web/backend/cli/core/skills → MINOR release; the previous release stays for rollback.

## Migration Plan

Implement in one change; rewrite mock fixtures and the operator's W0001 example; generate docs; release 6.9.0; deploy central; nodes pick up CLI/skills via `memon update`.
